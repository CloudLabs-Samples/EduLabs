# Task 3: Encrypt and Decrypt a Message

In this task, you will encrypt `message.txt` using your **public key**, then decrypt it using your **private key** — demonstrating the core promise of public-key encryption: anyone can lock the message, but only you can unlock it.

## Task 3.1: Encrypt the Message

1. Confirm you are in the `~/rsa-lab` directory.

   ```bash
   cd ~/rsa-lab
   ```

2. Encrypt `message.txt` using your public key, producing a binary ciphertext file.

   ```bash
   openssl pkeyutl -encrypt -pubin -inkey public_key.pem -in message.txt -out ciphertext.bin
   ```

3. Confirm the encrypted file was created.

   ```bash
   ls -la ciphertext.bin
   ```

4. Try to view it as text.

   ```bash
   cat ciphertext.bin
   ```

   > **Info:** You'll see unreadable binary output. This confirms the message is genuinely encrypted — it's no longer readable without the private key.

## Task 3.2: Decrypt the Message

1. Decrypt `ciphertext.bin` using your private key.

   ```bash
   openssl pkeyutl -decrypt -inkey private_key.pem -in ciphertext.bin -out decrypted.txt
   ```

2. View the decrypted result.

   ```bash
   cat decrypted.txt
   ```

3. Confirm the output matches the original message exactly:

   ```
   This message proves the CloudLabs RSA lab environment is ready.
   ```

## Task 3.3: Confirm the Round-Trip Was Lossless

1. Compare the original and decrypted files directly.

   ```bash
   diff message.txt decrypted.txt
   ```

2. Confirm the command produces **no output**.

   > **Info:** No output from `diff` means the two files are identical. This proves that encrypting and then decrypting the message returned it to its exact original state, with nothing lost or altered.

You have successfully encrypted and decrypted a message with RSA. Proceed to **Task 4**.
