# Summary

Congratulations — you have completed the RSA Public-Key Encryption & Digital Signatures lab.

## What You Accomplished

- **Task 1:** Verified your lab environment and explored the pre-provisioned working directory.
- **Task 2:** Generated an RSA public/private key pair.
- **Task 3:** Encrypted a message with a public key and decrypted it with the matching private key.
- **Task 4:** Used a SHA-256 hash to detect when a message had been tampered with.
- **Task 5:** Created a digital signature, verified it successfully, and observed verification fail after tampering.

## Key Takeaways

| Concept | What you proved |
|---|---|
| RSA Encryption | Only the private-key holder can read an encrypted message |
| SHA-256 Hashing | Any change to a message changes its fingerprint completely |
| Digital Signatures | A message's origin and integrity can be verified without exposing the private key |

These three concepts, working together, are the foundation of secure communication on the internet — from HTTPS websites to signed software updates to encrypted email.
