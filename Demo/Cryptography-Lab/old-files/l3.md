# Task 2: Generate an RSA Key Pair

RSA cryptography works with two mathematically linked keys:

- A **private key** — kept secret, never shared. Used to decrypt messages and create signatures.
- A **public key** — shared freely. Used to encrypt messages and verify signatures.

In this task, you will generate both.

## Task 2.1: Generate a Private Key

1. Make sure you are still in the `~/rsa-lab` directory.

   ```bash
   cd ~/rsa-lab
   ```

2. Generate a 2048-bit RSA private key.

   ```bash
   openssl genpkey -algorithm RSA -pkeyopt rsa_keygen_bits:2048 -out private_key.pem
   ```

   > **Note:** This step will take around 5–10 seconds to complete. You'll see the terminal return to a prompt when it's done — there is no progress bar.

3. Confirm the file was created.

   ```bash
   ls -la private_key.pem
   ```

## Task 2.2: Extract the Public Key

1. Derive the public key from your private key.

   ```bash
   openssl rsa -pubout -in private_key.pem -out public_key.pem
   ```

2. Confirm the file was created.

   ```bash
   ls -la public_key.pem
   ```

## Task 2.3: Inspect Your Keys

1. View the contents of your private key.

   ```bash
   cat private_key.pem
   ```

   > **Info:** This is a PEM-encoded block of text. You will never share this file with anyone or paste it anywhere outside this lab.

2. View the contents of your public key.

   ```bash
   cat public_key.pem
   ```

   > **Info:** Unlike the private key, this file is safe to share. In real-world use, this is the file you would hand out to anyone who needs to send you an encrypted message or verify your signature.

You now have a working RSA key pair. Proceed to **Task 3**.
