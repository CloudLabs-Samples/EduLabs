# Task 1: Verify Your Lab Environment

In this task, you will confirm that your lab environment was set up correctly before starting any cryptography work.

## Task 1.1: Confirm OpenSSL Is Available

1. Run the following command to check that `openssl` is installed and see its version.

   ```bash
   openssl version
   ```

2. Confirm the output looks similar to the following (the exact version number may differ):

   ```
   OpenSSL 3.0.13 30 Jan 2024
   ```

   > **Note:** If you see a "command not found" error instead, stop here and contact your lab support — this should not happen, as `openssl` is pre-installed on the VM image.

## Task 1.2: Explore Your Working Directory

1. Navigate to your lab working directory.

   ```bash
   cd ~/rsa-lab
   ```

2. List the contents of the directory.

   ```bash
   ls -la
   ```

3. Confirm you see the following three files:

   | File | Purpose |
   |---|---|
   | `message.txt` | The plaintext message you'll encrypt and sign |
   | `.original_message.sha256` | A stored hash of the untouched message, used in Task 4 |
   | `README.txt` | A short reminder of what's in this folder |

## Task 1.3: View the Starting Message

1. Display the contents of the message file.

   ```bash
   cat message.txt
   ```

2. Confirm you see the following text:

   ```
   This message proves the CloudLabs RSA lab environment is ready.
   ```

   > **Info:** Keep this terminal window open and stay inside the `~/rsa-lab` directory for the rest of the lab. Every remaining task assumes you're working from here.

You have confirmed your environment is ready. Proceed to **Task 2**.
