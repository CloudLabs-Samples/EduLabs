## Question
10. appvm uses a **system-assigned** managed identity. What happens to that identity if appvm is deleted?

## Options

Option 1 : It stays in Microsoft Entra ID as an orphaned principal until an administrator removes it and its roles

Option 2 : It is converted into a user-assigned identity in the resource group so that a replacement VM can reuse it later

Option 3 : It is suspended rather than deleted, and is reactivated automatically if a VM with the same name returns

Option 4 : It is deleted along with the VM, so any role assignments that referenced it stop granting access to anything

## Answers
Option 4 : 1
