# Lab 3A: DC FET curve tracer template

### Estimated Duration: 60 Minutes

## Overview

This step uses a built-in DC simulation template that sweeps drain-source voltage at different steps of gate-source voltage (also called a nested sweep). The resulting IDS or bias characteristics are plotted automatically using a built-in data display template.
