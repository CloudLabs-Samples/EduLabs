# Lab 01 - Module 6: Simulation setup

**Learning Objectives:** In this module, you will complete the following tasks:

- Frequency setup

- Display parameter

## Task 1: Frequency setup

1. Double click on the **S-parameter** simulation controller

   ![](../Image/01-e87355fb-5a77-4034-a3f5-f0b7511d9269.png)

1. Set **Step-size** = **0.5 GHz**

1. Click **Apply**

> **Note:** Notice how it updates the value on the screen. The OK button does the same thing as Apply, and it also dismisses the dialog box - **do not** click OK yet.

## Task 2: Display parameter

1. Click the right arrow to scroll the tabs until you see the **Display** tab.

   ![](../Image/01-3d6e992d-bcd2-4bc8-bc47-94dcecc963d5.png)

1. The **Start, Stop** and **Step** values have been checked (by default) to be displayed on the schematic. There are many hidden parameters associated with most components that can be displayed or made invisible on the schematic.

1. Click **OK**.

1. It should look like this

   ![](../Image/01-d9b254a1-0c99-4757-bd43-342cacdea3a9.png)

## You have successfully completed Lab 01 - Module 6.
