# Lab 3A - Module 1: Create amplifier workspace

**Learning Objectives:** In this module, you will complete the following tasks:

- Create amplifier workspace

- Add library

- Choose Technology for library

## Task 1: Create amplifier workspace

1. Click on the **New Workspace**

   ![](../Image/3A-6f96db14-e542-4346-a77b-64365b9eabef.png)


1. Set **Name** = **My_AMP_wrk**

   ![](../Image/3A-c9aff72c-dc9d-43e6-b2ca-3a66fb3b34e8.png)

1. Click Show advanced.

1. Check **Set up layout technology immediately...**

1. Click on Change Libraries.

   ![](../Image/3A-4eff02e0-361c-445a-9f90-b770877e3c87.png)

## Task 2: Add library

1. Select **DemoKit_Non_Linear** library

   ![](../Image/3A-30b128f6-db4a-41eb-8598-d94540bf8c43.png)

1. Click OK

1. Click **Create Workspace**

## Task 3: Choose Technology for library

1. Choose DemoKit_Non_Linear, 0.001 micron....

   ![](../Image/3A-32ed338d-2463-4f9b-824b-880afa49171d.png)

1. Click **Finish**

## You have successfully completed Lab 3A - Module 1.
