# Module 3: Examine the HB data

**Learning Objectives:** In this module, you will complete the following tasks:

- Spectrum of V_out in dbm
- Mixing table

## Task 1: Spectrum of V_out in dbm

   ![](https://raw.githubusercontent.com/CloudLabs-Samples/EduLabs/refs/heads/main/Keysight-Tech/ADS101-4A/LabGuidePackage/Image/f1c3f95e-82fd-41f4-9150-870eb6d02852.png)

1. In the data display **a3_sys_HB**, Insert a rectangular plot ![](https://raw.githubusercontent.com/CloudLabs-Samples/EduLabs/refs/heads/main/Keysight-Tech/ADS101-4A/LabGuidePackage/Image/ca19d80f-f9ef-4fc2-a47b-d557c500276b.png)

1. Add **Vout**

1. Select **Spectrum in dBm**.

1. Click **OK** twice

Place your mouse pointer on the 7 GHz trace as shown here.

   ![](https://raw.githubusercontent.com/CloudLabs-Samples/EduLabs/refs/heads/main/Keysight-Tech/ADS101-4A/LabGuidePackage/Image/image-6-1.png)

>**Note:** The output power is about 7 dBm at 7 GHz which corresponds to the 0 dBm input power, plus 10 dB gain, minus the 3.01 dB attenuation at that frequency in the LPF.

## Task 2: Mixing table

   ![](https://raw.githubusercontent.com/CloudLabs-Samples/EduLabs/refs/heads/main/Keysight-Tech/ADS101-4A/LabGuidePackage/Image/a41320a0-41e5-4e53-bc6e-868210406ee8.png)

1. Insert a **List**![](https://raw.githubusercontent.com/CloudLabs-Samples/EduLabs/refs/heads/main/Keysight-Tech/ADS101-4A/LabGuidePackage/Image/image-10.png)

1. Add **Mix**

1. Click OK

   ![](https://raw.githubusercontent.com/CloudLabs-Samples/EduLabs/refs/heads/main/Keysight-Tech/ADS101-4A/LabGuidePackage/Image/image-7.png)

>**Note:** Each frequency has an index number and also a mixing table which for 1-tone data is identical. But for intermodulation simulations, the mixing table makes it easy to select specific mixing terms out of the datasets.

**Save** and **close** the data display and the schematic.
