# Module 1: Create amplifier workspace

**Learning Objectives:** In this module, you will complete the following tasks:

- Create amplifier workspace
- Add library
- Choose Technology for library

## Task 1: Create amplifier workspace

1. Click on the **New Workspace**

![](https://raw.githubusercontent.com/CloudLabs-Samples/EduLabs/refs/heads/main/Demo/Keysight-tech/Keysight-Tech/ADS101-3B/LabGuidePackage/Image/6f96db14-e542-4346-a77b-64365b9eabef.png)

   ![](https://raw.githubusercontent.com/CloudLabs-Samples/EduLabs/refs/heads/main/Demo/Keysight-tech/Keysight-Tech/ADS101-3B/LabGuidePackage/Image/c9aff72c-dc9d-43e6-b2ca-3a66fb3b34e8.png)

1. Set **Name** = **My_AMP_wrk**

1. Click Show advanced

1. Check “Set up layout technology immediately..."

1. Click on ![](https://raw.githubusercontent.com/CloudLabs-Samples/EduLabs/refs/heads/main/Demo/Keysight-tech/Keysight-Tech/ADS101-3B/LabGuidePackage/Image/4eff02e0-361c-445a-9f90-b770877e3c87.png)

## Task 2: Add library

   ![](https://raw.githubusercontent.com/CloudLabs-Samples/EduLabs/refs/heads/main/Demo/Keysight-tech/Keysight-Tech/ADS101-3B/LabGuidePackage/Image/30b128f6-db4a-41eb-8598-d94540bf8c43.png)

1. Select **DemoKit_Non_Linear** library

1. Click OK

1. Click **Create Workspace**

## Task 3: Choose Technology for library

   ![](https://raw.githubusercontent.com/CloudLabs-Samples/EduLabs/refs/heads/main/Demo/Keysight-tech/Keysight-Tech/ADS101-3B/LabGuidePackage/Image/32ed338d-2463-4f9b-824b-880afa49171d.png)

1. Choose DemoKit_Non_Linear, 0.001 micron....

1. Click **Finish**
