# Lab 3B: FET Amplifier Design and Linear Analysis

### Estimated Duration: 120 Minutes

## Overview

This lab covers FET amplifier schematic and symbol design, DC/AC simulation with bias annotation, noise and frequency analysis, and advanced parameter sweeps using variable equations.
