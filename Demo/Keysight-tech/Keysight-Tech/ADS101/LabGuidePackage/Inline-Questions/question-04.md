## Question
4. True or False: In Lab 3B, a minus sign (-) on a DC-annotated current value means there is an error in the amplifier's bias circuit.

## Options

Option 1 : True

Option 2 : False

## Answers
Option 2 : 2

## Correct Answer Feedback
Correct! The statement is false. The minus sign is used only to show the direction of the current, out of or into a node.

## Incorrect Answer Feedback
Not quite. The statement is false. In DC annotation, the minus sign on a current value only indicates its direction (out of or into the node). It is not a warning or an error.
