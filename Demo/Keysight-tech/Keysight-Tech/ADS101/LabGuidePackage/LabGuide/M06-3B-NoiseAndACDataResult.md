# Lab 3B - Module 6: Noise and AC data result

**Learning Objectives:** In this module, you will complete the following tasks:

- Noise result
- AC data result

## Task 1: Noise result

   ![](https://raw.githubusercontent.com/CloudLabs-Samples/EduLabs/refs/heads/main/Keysight-Tech/ADS101-3B/LabGuidePackage/Image/304c2aaa-efb6-4506-96d5-b7d0878e5cf1.png)

1. In the Data Display, insert a **List**![](https://raw.githubusercontent.com/CloudLabs-Samples/EduLabs/refs/heads/main/Keysight-Tech/ADS101-3B/LabGuidePackage/Image/image-37.png)

1. Select both (use Ctrl key) **Vin.noise** and **Vout.noise**. **Add** them.

1. Click **OK**.

You should have these values in table below.

   ![](https://raw.githubusercontent.com/CloudLabs-Samples/EduLabs/refs/heads/main/Keysight-Tech/ADS101-3B/LabGuidePackage/Image/d9b5d485-8924-4b4f-a141-1e6173a2609c.png)

>**Note:** This shows that the noise level at the output pin is about 1.8 nano volts. It will be different at other points in the circuit.

## Task 2: AC data result

   ![](https://raw.githubusercontent.com/CloudLabs-Samples/EduLabs/refs/heads/main/Keysight-Tech/ADS101-3B/LabGuidePackage/Image/d9c59eca-586a-4ed9-9329-00401f8e584e.png)

1. Insert another List ![](https://raw.githubusercontent.com/CloudLabs-Samples/EduLabs/refs/heads/main/Keysight-Tech/ADS101-3B/LabGuidePackage/Image/image-37-1.png)

1. Select both **AC.Vin** and **AC.Vout**. **Add** them.

1. Click **OK**.

You should have these values in table below.

   ![](https://raw.githubusercontent.com/CloudLabs-Samples/EduLabs/refs/heads/main/Keysight-Tech/ADS101-3B/LabGuidePackage/Image/edb3a53b-887c-46df-b7e6-702bdfa00892.png)

>**Note:** The AC results are in magnitude/phase format by default while the noise results are in volts rms.
