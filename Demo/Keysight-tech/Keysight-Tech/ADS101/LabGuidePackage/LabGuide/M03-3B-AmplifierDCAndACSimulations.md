# Lab 3B - Module 3: Amplifier DC and AC simulations

**Learning Objectives:** In this module, you will complete the following tasks:

- Create new schematic
- Insert amplifier symbol
- Insert V_AC source
- Insert resistor
- Place wire label

## Task 1: Create new schematic

   ![](https://raw.githubusercontent.com/CloudLabs-Samples/EduLabs/refs/heads/main/Keysight-Tech/ADS101-3B/LabGuidePackage/Image/b2add6fc-522a-4be4-8694-748e6fcdcef1.png)

1. Click **New Schematic Window**![](https://raw.githubusercontent.com/CloudLabs-Samples/EduLabs/refs/heads/main/Keysight-Tech/ADS101-3B/LabGuidePackage/Image/369133d5-461e-4586-8346-d384b7bd3397.png)

1. Name the new cell **AMP_test_DC_AC**

1. Click **Create Schematic**

## Task 2: Insert amplifier symbol

1. **Drag & drop** symbol for the amplifier from the Main window or search for its name in the Parts search field in the schematic.

![](https://raw.githubusercontent.com/CloudLabs-Samples/EduLabs/refs/heads/main/Keysight-Tech/ADS101-3B/LabGuidePackage/Image/image-26.png)

## Task 3: Insert V_AC source

   ![](https://raw.githubusercontent.com/CloudLabs-Samples/EduLabs/refs/heads/main/Keysight-Tech/ADS101-3B/LabGuidePackage/Image/image-27.png)

1. Select **Sources-Freq Domain** palette

1. Insert a **V_AC** source.

1. Wire on the input side of the amplifier.

1. Add a ground ![](https://raw.githubusercontent.com/CloudLabs-Samples/EduLabs/refs/heads/main/Keysight-Tech/ADS101-3B/LabGuidePackage/Image/c46e9523-adfa-4773-81ee-99aa5c0221fb.png)

## Task 4: Insert resistor

   ![](https://raw.githubusercontent.com/CloudLabs-Samples/EduLabs/refs/heads/main/Keysight-Tech/ADS101-3B/LabGuidePackage/Image/image-28.png)

1. Type the letter “**R**” in the Parts search field.

1. Insert a **resistor** (CTRL R to rotate).

1. Wire it to the amplifier output

1. Add a ground.

## Task 5: Place wire label

In DC and AC simulations, to obtain simulation results, you must have wire labels, current probes and/or power probes in your circuit.

   ![](https://raw.githubusercontent.com/CloudLabs-Samples/EduLabs/refs/heads/main/Keysight-Tech/ADS101-3B/LabGuidePackage/Image/7658db49-44c9-4cca-a303-49d17308cfb1.png)

1. Click the **NAME** icon ![](https://raw.githubusercontent.com/CloudLabs-Samples/EduLabs/refs/heads/main/Keysight-Tech/ADS101-3B/LabGuidePackage/Image/b6336714-e0ac-4f59-96b5-1f92f8bb0f9d.png) (or menu command: *Insert > Wire/Pin Label* ).

1. Select the input wire, type **Vin.**

1. Select the output wire and type **Vout.**
